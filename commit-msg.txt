Web: fix app hanging on splash in the browser; add static hosting config

Root cause: expo-secure-store has no web implementation, so AuthContext's
bootstrap (tokenStorage.load -> SecureStore.getItemAsync) threw on web and the
app never left the "Loading your data..." state. Found and confirmed in a real
browser run (TypeError: getValueWithKeyAsync is not a function), not by unit
tests -- jest.setup.ts mocks expo-secure-store, which hid it.

Fix: platform-split storage in src/auth/tokenStorage.ts. Native keeps
expo-secure-store; web falls back to localStorage (documented as acceptable for
a browser demo, not the production answer: httpOnly cookies / BFF).

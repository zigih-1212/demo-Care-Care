# Cara Care — Backend (demo)

Digital-therapeutic backend for IBS/GERD symptom tracking and therapy programs.
See the repository root `README.md` for the full architecture overview.

## Quickstart

```bash
uv venv --python 3.12
uv pip install -e ".[dev]"
python manage.py migrate
python manage.py runserver
```

Full documentation is maintained at the repository root (`README.md`,
`docs/ARCHITECTURE.md`, `docs/COMPLIANCE.md`, `docs/RUNBOOK.md`).
